앱 권한 경계 점검 · v0.5.0

사용자마다 달라야 할 접근 권한,
출시 전에 확인하세요.

BoundaryCheck는 테스트 계정과 API 요청을 정리하고, 내장된 가상 예제에서 사용자·조직 사이의 접근 경계 검사 흐름을 확인하는 Windows 프로그램입니다.

프로그램 다운로드작동 방식 보기
프로젝트와 테스트 자료는 설치형 Windows 프로그램 안에서만 다룹니다. 이 웹사이트에는 테스트 기능이 없습니다.

요청 자료 가져오기

HAR 또는 OpenAPI JSON에서 API 요청 경로를 읽어 테스트 초안을 만듭니다.

제한된 쓰기 예제

다중 동의 후 가상 데이터만 바꾸는 PATCH 흐름을 확인합니다. 실제 API 요청은 실행하지 않습니다.

검사 보고서

검사 범위와 결과를 JSON으로 저장하고 다시 엽니다. 응답 본문은 파일에 넣지 않습니다.

Windows 프로그램 · v0.5.0

압축을 푼 뒤 BoundaryCheck.exe를 실행하세요. Windows x64용 자체 포함 패키지입니다.

프로그램 다운로드
BoundaryCheck는 앱 전체의 안전을 보증하지 않습니다. 허가받은 테스트 환경에서만 사용하세요.
