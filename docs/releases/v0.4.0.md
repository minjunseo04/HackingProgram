# v0.4.0 — 검사 결과 보고서

- 내장 안전·취약 예제 실행 결과를 JSON 파일로 저장하고 다시 엽니다.
- 예제별 검사 항목, 테스트 신원, 요청 경로, 기대 접근값, 실제 HTTP 상태, 소유자 대조 상태, 판정 및 판정 이유를 기록합니다.
- 실행 시각, 앱 버전, 실행 모드, 검사 범위와 검사하지 않은 항목을 기록합니다.
- 사용자 프로젝트, 대상 주소, HAR/OpenAPI 자료, 인증 비밀, 응답 본문은 보고서에 넣지 않습니다.
- 보고서 파일은 사용자가 저장 위치를 선택하며, 수정 가능한 요약 파일입니다. 변조 방지 서명은 제공하지 않습니다.
- 검사는 기존처럼 내장된 가상 예제와 loopback 임시 포트에만 한정됩니다. 사용자가 가져온 실제 API 요청을 실행하지 않습니다.

GitHub Actions Windows x64 패키지 빌드 후 GitHub Release에 게시합니다.
