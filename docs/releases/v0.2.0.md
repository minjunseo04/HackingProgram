# v0.2.0

- 이름·조직·역할로 테스트 신원을 추가·수정·삭제합니다.
- 같은 요청 경로를 복제해 서로 다른 신원에 연결할 수 있습니다.
- 각 요청·신원 조합에 기대 접근값(미지정/허용/거부)을 기록합니다.
- 신원과 요청 규칙을 로컬 프로젝트 파일에 저장하며 기존 v0.1.3 저장 파일도 불러올 수 있습니다.
- 신원을 삭제하면 연결된 요청이 신원 미지정·기대값 미지정으로 돌아갑니다.
- 로그인 비밀번호·토큰 등 인증 정보 입력과 실제 API 요청 실행은 포함하지 않습니다.

v0.2.0은 GitHub Release로 공개됐습니다. Windows ZIP은 GitHub Actions가 빌드했습니다.
