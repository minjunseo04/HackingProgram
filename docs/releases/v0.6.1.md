# v0.6.1 — 한글 글꼴과 작업 공간 화면 수정

## 변경 사항

- 설치된 Windows 글꼴을 확인해 한국어 화면에서 `맑은 고딕`을 우선 사용합니다. 설치되지 않은 영문 글꼴 이름에 의존하지 않습니다.
- 프로젝트 설정 라벨을 입력칸 위로 옮기고, 사이드바 폭과 글자 크기를 조정했습니다.
- 메인 작업 공간, 테스트 신원 관리, 내장 로컬 예제 화면에 공통 글꼴 설정을 적용했습니다.

## 동작 및 범위

- API 요청 검사 범위, 로컬 저장 자료 형식, 업데이트 동작은 변경하지 않았습니다.
- 확인: Windows Release 빌드 성공(경고 0, 오류 0), 메인·신원 관리·로컬 예제 화면 실행.
- 실제 사용자 PC의 설치·업데이트 흐름은 사용자가 다운로드한 Release에서 확인해야 합니다.
