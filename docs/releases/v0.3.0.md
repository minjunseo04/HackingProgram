# v0.3.0 — 초안, 아직 미공개

- 저장 프로젝트와 분리된 내장 로컬 예제 실행 화면을 추가합니다.
- 안전 모드와 교차 조직 읽기가 허용되는 취약 모드를 각각 실행합니다.
- 가상 Acme/Birch 계정, 고정된 예제 경로, 임시 loopback 포트만 사용합니다.
- GET 요청만 전송하고 프록시·리디렉션을 끕니다.
- 소유자 대조 요청이 성공하지 않으면 권한 거부를 통과로 처리하지 않고 판정 보류합니다.
- 응답 본문과 가상 인증 정보는 저장하지 않습니다.
- 사용자가 가져온 실제 API 요청, 저장된 신원, 대상 주소 검사 및 보고서 내보내기는 포함하지 않습니다.

Windows x64 ZIP은 로컬에서 생성했습니다. 공개 전 앱에서 안전·취약 예제 화면과 판정 결과를 확인해야 합니다.
