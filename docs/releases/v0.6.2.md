# v0.6.2 — 앱 내 업데이트 복구

## 변경 사항

- PowerShell 업데이트 도우미를 Windows 실행 파일에 포함합니다. 앱 설치 폴더에 별도 `apply-update.ps1` 파일이 없어도 사용자 로컬 업데이트 폴더에 내장 스크립트를 꺼내 업데이트를 적용합니다.
- 다운로드 ZIP은 계속 SHA-256을 검증하고, 압축 경로와 허용 파일 이름을 확인합니다. ZIP 안의 별도 도우미 스크립트는 더 이상 필수 항목이 아닙니다.
- 배포 ZIP에는 이전 앱과의 호환을 위해 `apply-update.ps1`을 계속 포함합니다.

## 기존 v0.6.0 앱에서 복구

v0.6.0 실행 파일은 업데이트 도우미가 없으면 업데이트 전에 중단하므로 스스로 복구할 수 없습니다. 공식 v0.6.2 ZIP 전체를 새 폴더에 압축 해제하고, 그 안의 `BoundaryCheck.exe`를 한 번 실행해야 합니다. 프로젝트 데이터는 `%LOCALAPPDATA%`에 남아 있습니다.
