# v0.5.0 — 동의 기반 메모리 쓰기 예제

- 쓰기 검사는 내장된 loopback 예제에서만 실행할 수 있습니다.
- 기본값은 꺼짐입니다. 앱 설정의 영구 허용, 실행 창의 실행별 동의, 실행 전 최종 확인을 모두 요구합니다.
- 고정된 PATCH는 최대 4회, 상태 확인 GET은 최대 2회만 임시 `127.0.0.1` fixture로 보냅니다. Acme 소유자 쓰기 대조가 성공해야만 Birch 쓰기를 진행합니다.
- Acme/Birch 가상 문서 라벨만 서버 메모리에서 바꾸며 예제 종료 후 폐기합니다.
- 저장 프로젝트, 대상 주소, 가져온 파일, 실제 서비스는 사용하지 않습니다.
- JSON 결과 보고서는 쓰기 검사 범위와 상태를 기록하며, 응답 본문은 저장하지 않습니다.
- v0.4.0 JSON 보고서 형식을 계속 열 수 있습니다.

GitHub Actions Windows x64 패키지 빌드 후 GitHub Release에 게시합니다.
