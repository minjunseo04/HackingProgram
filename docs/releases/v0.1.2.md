# v0.1.2

- 앱에서 사용자가 직접 최신 GitHub Release를 확인하고 새 버전을 내려받는다.
- 확인 전에 GitHub가 요청자의 IP 주소와 앱 버전을 볼 수 있음을 알린다. 프로젝트 이름, 대상 주소, 요청 목록은 전송하지 않는다.
- 다운로드 ZIP을 GitHub가 제공하는 SHA-256 digest와 대조하고, ZIP 안의 파일 목록을 확인한 뒤에만 현재 실행 파일을 바꾼다.
- `v*.*.*` 태그가 push되면 GitHub Actions가 Windows ZIP을 만들고 Release에 게시한다.
- v0.1.1 앱에는 업데이트 코드가 없으므로 업데이트 흐름이 포함된 다음 배포본(v0.1.3)을 한 번 직접 내려받아야 한다. 이후 버전부터 앱에서 업데이트할 수 있다.

이 흐름은 GitHub의 [Release asset API](https://docs.github.com/en/rest/releases/assets)와 [Actions workflow 권한](https://docs.github.com/en/actions/reference/workflows-and-actions/workflow-syntax)을 사용한다.
