# v0.6.3 — Windows 화면 배율 레이아웃 수정

## 변경 사항

- Windows DPI 배율에 따라 고정 크기 컨테이너, 여백, 행·열, 버튼과 표를 조정합니다.
- 메인 작업 공간, 테스트 신원 관리, 로컬 예제 창에서 큰 글꼴 배율로 콘텐츠가 잘리는 문제를 수정합니다.
- DPI가 다른 모니터로 이동할 때 레이아웃에 변경 배율을 적용합니다.
- 검사 범위와 저장 형식은 변경하지 않습니다.

## 확인

- 로컬 Release 빌드 성공: 경고 0개, 오류 0개.
- 현재 Windows에서 메인 화면의 제목·통계·설정·요청 목록과 로컬 예제 창 전체 안내문을 확인했습니다.
- GitHub Actions 패키지 빌드와 공개 자산 검수 결과는 게시 후 기록합니다.
