# v0.6.7 — 중복 실행 방지

## 변경 사항

- Windows named mutex로 BoundaryCheck를 한 번만 실행하도록 한다.
- 다시 실행하면 기존 창을 복원하고 앞으로 가져온다. 첫 창이 뜨는 중인 경우 활성화 신호로 기존 인스턴스에 전달한다.
- 이전 버전 앱이 같은 세션에서 실행 중인 경우도 창 제목과 프로세스를 확인해 기존 창을 우선 활성화한다.
