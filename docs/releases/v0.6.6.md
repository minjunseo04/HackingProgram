# v0.6.6 — 가져올 파일 준비 안내

## 변경 사항

- 가져오기 버튼을 “브라우저 기록 파일”과 “API 문서 파일”로 바꾸고, 앱 안에 필요한 파일 안내를 추가했다.
- Chrome/Edge 개발자 도구에서 HAR를 내보내는 순서와 개발 담당자에게 요청할 OpenAPI 3.0/3.1 JSON 파일을 설명한다.
- HAR에 로그인 쿠키나 토큰이 들어 있을 수 있다는 점, 가져오는 범위와 실제 요청이 전송되지 않는다는 한계를 안내한다.
- HAR/OpenAPI 파일 형식이 맞지 않거나 결과가 없을 때 다음 확인 항목을 보여준다.
- 사용자의 명시적 요청 전에는 사용성 테스트를 진행하지 않는다.
