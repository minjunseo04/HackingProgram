# v0.6.5 — 첫 화면 작업 안내

## 변경 사항

- 첫 화면 제목을 “권한 점검 시작”으로 바꾸고, 프로젝트 범위 → 요청 가져오기 → 신원·기대 규칙 → 로컬 예제 결과 순서를 배치했습니다.
- 현재 가져온 HAR/OpenAPI 요청은 대상에 전송되지 않고 내장 로컬 예제만 실행할 수 있다는 제한을 첫 화면에 표시합니다.
- 단계별 바로가기와 요청·신원 수를 보여줍니다. 프로젝트 주소와 API 경로는 가져오기 필터로 이름을 바꿔 실제 검사 주소로 오해하지 않도록 했습니다.
- 표 머리글의 선택 상태가 파란색으로 강조되지 않게 조정했습니다.
- 실제 프로젝트 요청 검사 기능은 이번 버전에 포함하지 않았습니다.
