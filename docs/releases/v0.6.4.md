# v0.6.4 — 화면 높이 맞춤 및 내장 예제 검수

## 변경 사항

- DPI 적용 뒤 메인 작업 공간의 남은 높이를 계산해 요청 목록 카드 크기를 맞춥니다.
- 화면 높이가 충분하면 요청 목록의 마지막 요약 줄까지 보입니다. 최소 카드 높이보다 작은 창에서는 자동 스크롤로 나머지 내용을 볼 수 있습니다.
- 검사 범위, 프로젝트 형식, 저장 동작은 바꾸지 않았습니다.

## 확인

- 로컬 Release 빌드 성공: 경고 0개, 오류 0개.
- 새 빌드의 메인 화면에서 요청 목록 요약까지 보이는 것을 확인했습니다.
- 내장 안전 읽기: Acme 소유자 요청 200, Birch 교차 조직 요청 404로 기대와 일치했습니다. 없는 경로는 소유자 대조도 404여서 판정 보류였습니다.
- 내장 취약 읽기: Acme 소유자 요청 200, Birch 교차 조직 요청도 200으로 검토 필요를 표시했습니다. 없는 경로는 소유자 대조도 404여서 판정 보류였습니다.
- 제한 쓰기 검사: 안전 모드 `204/403/204`는 모두 기대와 일치했고, 취약 모드 `204/204/409`는 교차 조직 쓰기 및 소유자 라벨 변경을 검토 대상으로 표시했습니다.
- 쓰기 검사 창을 닫고 다시 열어 동일 예제를 실행했을 때 결과가 같았습니다. 새 임시 fixture가 초기 메모리 상태로 시작하는 것을 확인했습니다.
- 모든 예제 요청은 설치 앱 내장 fixture의 `127.0.0.1` 임시 포트만 사용했습니다. 테스트 후 앱 쓰기 허용 설정을 기본 꺼짐으로 돌렸습니다.
- GitHub Actions 및 공개 자산 검수는 태그 게시 후 기록합니다.
